STEP10 — настройка трёх учётных записей

1. Firebase Console -> Authentication -> Sign-in method.
   Оставьте включённым Anonymous (он нужен обычным посетителям) и дополнительно включите Email/Password.

2. Firebase Console -> Authentication -> Users -> Add user.
   Создайте ровно 3 пользователя с этими email:

   Владелец:
   owner.toe2691@example.com

   Администратор 1:
   admin1.toe2691@example.com

   Администратор 2:
   admin2.toe2691@example.com

   Пароли задайте сами. Пароли НЕ нужно добавлять в файлы сайта и НЕ нужно публиковать на GitHub.

3. На самом сайте для входа используются короткие логины:
   owner
   admin1
   admin2

4. Firebase Console -> Firestore Database -> Rules.
   Замените правила содержимым файла firestore.rules и нажмите Publish.

Права:
- Посетитель: только просмотр.
- owner: полный доступ ко всему.
- admin1/admin2: только журнал и расписание.

Важно: если Email/Password не включён или пользователи не созданы, вход редактора работать не будет.


STEP11 — УПРАВЛЕНИЕ ПРАВАМИ
-----------------------------
После входа owner откройте Настройки. Появится блок «Права администраторов».
Для admin1 и admin2 можно отдельно включить/выключить:
- редактирование журнала;
- редактирование расписания.

После изменения нажмите «Сохранить права». Права хранятся в Firestore:
toe_group / shared / access / admin_permissions

ВАЖНО: после обновления сайта обязательно опубликуйте новый firestore.rules из этого архива.
Именно Rules не дают администратору обойти выключенное право через DevTools.


STEP14 — РАСШИРЕННЫЕ ПРАВА
============================
Владелец может независимо выдавать admin1/admin2:
- Журнал
- Расписание
- Главная информация
- Состав группы
- Резервные копии
- Управление правами администраторов

Если право выключено, элементы редактирования этого раздела скрываются полностью.
Обязательно заменить Firestore Rules полным содержимым нового firestore.rules и нажать Publish.
