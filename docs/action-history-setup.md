# Общая история действий / Ортақ әрекеттер тарихы

Версия 18.47 записывает изменения журнала и расписания. Пока правила Firestore не обновлены, записи остаются на устройстве и интерфейс сообщает, что общая история недоступна. Публикация сайта через GitHub Pages не публикует правила Firebase.

18.47 нұсқасы журнал мен кесте өзгерістерін жазады. Firestore ережелері жаңартылмаса, жазбалар құрылғыда қалады және интерфейс ортақ тарихтың қолжетімсіз екенін көрсетеді. GitHub Pages арқылы сайтты жариялау Firebase ережелерін жарияламайды.

## Публикация / Жариялау

1. Откройте Firebase Console → проект `sbpgroup-toe-26-9-1` → Firestore Database → Rules. Сохраните копию текущих правил. / Firebase Console → `sbpgroup-toe-26-9-1` жобасы → Firestore Database → Rules бөлімін ашыңыз. Ағымдағы ережелердің көшірмесін сақтаңыз.
2. Сравните действующие правила с `firestore.rules` в репозитории. Новый раздел — `/toe_group/shared/audit_logs/{auditId}`. Остальные разделы сохранены. Если правила в консоли уже отличаются, добавьте только новый раздел внутрь существующего `match /databases/{database}/documents`, сохранив изменения в консоли. / Қолданыстағы ережелерді репозиторийдегі `firestore.rules` файлымен салыстырыңыз. Жаңа бөлім — `/toe_group/shared/audit_logs/{auditId}`. Басқа бөлімдер сақталған. Консольдегі ережелер өзгеше болса, тек жаңа бөлімді қолданыстағы `match /databases/{database}/documents` ішіне қосып, консольдегі өзгерістерді сақтаңыз.
3. Нажмите Publish. / Publish түймесін басыңыз.
4. На сайте войдите владельцем → меню → «История действий» → «Проверить подключение». Статус должен смениться на «Общая история группы». / Сайтта иесі ретінде кіріңіз → мәзір → «Әрекеттер тарихы» → «Байланысты тексеру». Күй «Топтың ортақ тарихы» болып өзгеруі тиіс.
5. Измените одну отметку, затем верните её. Убедитесь, что обе операции видны со старым и новым значением на другом устройстве администратора. У посетителя пункт истории отсутствует; прямое чтение коллекции посетителем правила запрещают. / Бір қатысу белгісін өзгертіп, қайта қайтарыңыз. Екі әрекеттің бұрынғы және жаңа мәндері әкімшінің басқа құрылғысында көрінетінін тексеріңіз. Келушіде тарих мәзірі жоқ; ережелер келушінің жинақты тікелей оқуына тыйым салады.

Из авторизованного Firebase CLI: / Авторизацияланған Firebase CLI арқылы:

```sh

```

История доступна владельцу и администраторам с правом на журнал или расписание. Автор записи проверяется по Firebase UID и учётной записи. Записи можно только добавлять; изменять и удалять их клиенту запрещено. Запрос истории ограничен 100 последними серверными записями.

Тарих иесіне және журнал немесе кесте құқығы бар әкімшілерге қолжетімді. Жазба авторы Firebase UID және тіркелгі арқылы тексеріледі. Клиент жазбаларды тек қоса алады; өзгерту мен жоюға тыйым салынады. Тарих сұрауы сервердегі соңғы 100 жазбамен шектеледі.

Это пользовательская история с версии 18.47, а не полный серверный аудит: старые версии сайта не создают записи, а сохранение данных и истории выполняется отдельными запросами. Очередь истории на устройстве сохраняет подтверждённые изменения и повторяет отправку после подключения. Исторические изменения задним числом не восстанавливаются.

Бұл — 18.47 нұсқасынан бастап пайдаланушы әрекеттерінің тарихы; толық серверлік аудит емес. Сайттың ескі нұсқалары жазба жасамайды, ал деректер мен тарих бөлек сұраулармен сақталады. Құрылғыдағы тарих кезегі расталған өзгерістерді сақтап, байланыс орнағаннан кейін қайта жібереді. Бұрынғы өзгерістер кейіннен қалпына келтірілмейді.
